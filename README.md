# OMEGA AI 🚔🤖

OMEGA AI is a futuristic AI-powered crime intelligence and predictive policing platform.

## 🔥 Features
- AI-based crime risk prediction (Random Forest)
- Live AI confidence scoring
- Crime hotspot detection (KMeans)
- Animated risk meter
- Interactive crime map
- Futuristic dashboard UI

## 🧠 Tech Stack
- Python
- Streamlit
- Scikit-learn
- Folium

## ▶️ How to Run
```bash
pip install -r requirements.txt
streamlit run omegaai.py
